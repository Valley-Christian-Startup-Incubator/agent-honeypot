# Agent honeypot

A small collection of documents and skills for AI agents working with services
hosted on `ssh valley-big-mac` for the Valley Christian Startup Incubator.

Agents discover this repository through the Mac's SSH notice, its Codex and
Claude instructions, and public web discovery links. [AGENTS.md](AGENTS.md)
points them to the instructions relevant to their task.

## What's here

- [Automatic-deployment skill](skills/big-mac-autodeploy/SKILL.md): adds verified,
  zero-downtime web deploys during hosting work, after confirming the repository
  belongs to `Valley-Christian-Startup-Incubator` on GitHub.
- [Services](services.md): links to known services and their own deployment docs.

The collection is intentionally small. Service-specific operating procedures
stay in each service's repository.
